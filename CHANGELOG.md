# Changelog

This file records user-facing changes to PyFlowMap.

## [1.0.0] — current local distribution

Initial publicly documented baseline:

- Static analysis of Python source without importing or executing
  the analyzed project.
- Activity, UML class, and UML package diagram generation.
- Editable Mermaid and Graphviz outputs, source-linked JSON, and
  optional SVG/PNG rendering.
- Command-line interface and optional MCP server.
- Optional, explicit semantic labeling separate from deterministic
  graph structure.
- Synthetic regression fixtures and independent benchmark suites.
- Local wheel and source distribution builds with isolated installation
  checks; no PyPI upload.

The 1.0.0 artifacts are built locally; this entry does not represent
a PyPI release or a published GitHub Release.

## Maintenance policy

Future entries should describe released behavior, compatibility or
security changes. Do not infer historic releases from previous commits.
