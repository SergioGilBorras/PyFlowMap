# Visual reference gallery (benchmark)

This is the original static three-diagram example retained as **benchmark reference material**, not a marketing site or a deployable GitHub Pages source. The HTML and SVG examples use the independently authored `examples/uml_showcase` source. Do not publish this folder as the consumer site.

For an exhaustive regenerated benchmark gallery, run the existing `scripts/validate_diagram_families.py` developer command, which writes results into an ignored dated `output_graphs/` directory. Do not commit those generated reports.

Open `index.html` locally to inspect the reference diagrams. All assets are self-contained.
